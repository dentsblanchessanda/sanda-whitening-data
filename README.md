# 三田・三田市ホワイトニング実測データビューア

ダンブランシュサンダ（dents Blanches SANDA）が公開する、ホワイトニング施術前後193件のシェード集計データを前歯・犬歯別に確認できるデータビューアです。

## 公開データ

- 集計対象：193件
- 前歯が白い方向へ変化：179件（92.7%）
- 犬歯が白い方向へ変化：177件（91.7%）
- 前歯・犬歯とも白い方向へ変化：174件（90.2%）
- 変化段階の中央値：前歯・犬歯とも4段階
